# Historical direction and current status

This file records earlier directions; it is not the current public-site specification. The latest user handoff supersedes the earlier investor-oriented public architecture and the earlier instruction to defer form handling.

## Retained platform thesis

Omnia OS is a proposed foundation for custom business systems. Reusable capabilities could support multiple client solutions, but scalability, deployment economics, and competitive advantage are not proven. Detailed architecture belongs primarily in technical and investor discussions. The public website keeps only an optional, concise explanation of Omnia OS as in development.

## Current form direction

The latest brief asks for distinct routes for launch-update interest and serious conversations, with real handling where possible. The site now contains native Netlify Forms for both. They do not simulate local success. Before collecting submissions, the site owner must enable form detection, verify the deployed forms, configure notifications/access, and provide the required privacy and retention information.
