# Integration identity assets

These identify illustrative integration targets. No partnership, affiliation or completed integration is claimed.

## Local vector marks — global platforms

- Stripe, Shopify, WhatsApp and Meta: sourced from Simple Icons (`https://github.com/simple-icons/simple-icons/tree/develop/icons`), CC0-1.0. These are third-party vector representations of the respective brands, not files downloaded from the companies' brand-kit pages. Brand colors follow the current Simple Icons metadata, with official source/guideline URLs retained in BRAND_SOURCES.json.
- Google: the original-color G mark is sourced from `https://raw.githubusercontent.com/gilbarbara/logos/main/logos/google-icon.svg` and identifies the Google Workspace target.
- Microsoft: sourced from `https://raw.githubusercontent.com/gilbarbara/logos/main/logos/microsoft-icon.svg`. The Microsoft corporate mark identifies the Microsoft 365 platform target. Its original colors and proportions are retained.

## Local vector marks — regional platforms

The regional marks are now stored locally. They replace the earlier runtime favicon-cache approach, so no third-party request is made for any identity asset on the page.

- Wafeq: the official mark is extracted from the company site's footer logo (`https://www.wafeq.com`, `viewBox 0 0 46 37`, Wafeq indigo `#505EDD`). It identifies the Wafeq accounting target.
- Foodics: the official "F" symbol is extracted from the company's official logo file (`https://www.foodics.com/wp-content/uploads/2021/12/foodics-logo.svg`, Foodics purple `#5B2EFF`). It identifies the Foodics restaurant-management target.
- Ziina: the official rosette mark is extracted from the company site (`https://ziina.com`, `viewBox 0 0 64 64`). It identifies the Ziina payments target.
- Telr: the official transparent logo PNG is downloaded from the company site's CDN (`https://cdn.prod.website-files.com/.../Logo%20telr%20PNG-01%20Green%20Transparent%20(1)-p-500.png`, served by `https://telr.com`). It identifies the Telr payments target.

The trademarks remain the property of their owners.

## Provenance note

Global marks were previously documented as verified local assets; the four regional marks were previously loaded at runtime through Google's favicon cache with a plain-text fallback. The favicon-cache approach has been retired: the current files are locally hosted, rendered at consistent sizes, and produce no external requests. Sources were fetched directly from the companies' own websites in October 2026.
